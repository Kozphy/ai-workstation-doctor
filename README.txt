Llama Server AutoStart
- install.ps1    : start llama server automatically (hidden) every time you log in
- stop-llama.ps1 : stop the running server
- uninstall.ps1  : turn off auto-start
- llama-server.log : server output
Server address: http://127.0.0.1:9931
Run a script: powershell -NoProfile -ExecutionPolicy Bypass -File <script>
